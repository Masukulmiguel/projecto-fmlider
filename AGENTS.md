# FMLider - Regras do Projecto

## Stack
- Vue.js 3 + Vite + Bootstrap 5
- PHP puro (API REST)
- MySQL 8
- Supabase (auth)

## Comandos
- `cd frontend && npm run dev` - Iniciar frontend
- `cd frontend && npm run build` - Build produção

## Convenções de Código
- Componentes Vue: PascalCase (ex: `ServiceCard.vue`)
- Stores: camelCase (ex: `authStore.js`)
- Ficheiros de páginas: PascalCase (ex: `Home.vue`)

## Regras
- Sempre usar design responsivo (mobile-first)
- Manter consistência visual com o design existente
- Usar os namespaces Supabase existentes
- Não alterar estrutura de pastas sem confirmar

## Contexto
- Empresa de logística e trânsito aduaneiro em Angola
- Site com mensagem de manutenção activa
- Painel de cliente em desenvolvimento
